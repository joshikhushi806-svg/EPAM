# EPAM Learning Track – Security

## Topic 12: Security

### Overview
Security focuses on protecting AI systems, sensitive information, and ensuring safe access to data and tools.

### Subtopics

#### 1. Data Handling
- Types of data and sensitive information
- Data privacy and protection
- Secure data storage
- Safe handling of user information

#### 2. Secrets Management
- What are secrets?
- API keys and access tokens
- Environment variables
- Secure storage of credentials

#### 3. Prompt Injection
- Introduction to prompt injection
- Direct and indirect prompt injection
- Risks of prompt injection in AI systems
- Prevention and mitigation techniques

#### 4. Safe Access
- Authentication and authorization
- Role-based access control (RBAC)
- Least privilege principle
- Secure access to tools and resources

### Learning Objectives
- Understand security risks in AI systems.
- Protect sensitive data and credentials.
- Identify and prevent prompt injection attacks.
- Implement safe access practices.

### Conclusion
Security helps build reliable, safe, and trustworthy AI applications.
